# 深度能源与气候政策实验室

为深度减碳提供深度分析与深度见解

深度能源与气候政策实验室（简称“深度政策实验室”）由纽约市立大学[何钢](https://drganghe.github.io/cn.html)老师团队创建，旨在通过数据驱动方法对能源与气候政策（DEEP）进行深度分析和研究，为明智的能源决策和气候行动提供支持，以实现深度减碳应对气候变化。

我们的使命是通过严谨的数据分析和协作对话，推动有效的能源和气候解决方案。我们积极与学术机构、政府部门、行业伙伴和民间组织合作，推动能源与气候政策领域的创新和行动。

我们综合利用能源系统建模、技术经济分析、大数据和人工智能、以及社会科学，为可再生能源、清洁能源供应链、深度减碳以及其他对能源转型和实现碳中和至关重要的领域的政策制定提供决策支持。

深度政策实验室主要研究领域：

- [可持续、韧性及公正的清洁能源供应链](research/clean-energy-supply-chains/index.llms.md)  
- [电力系统低碳转型](research/power-systems-decarbonization/index.llms.md)  
- [气候变化对能源系统的影响](research/climate-impacts-energy-systems/index.llms.md)  
- [能源交叉研究](research/energy-nexus-research/index.llms.md)  
- [能源与气候公正](research/energy-climate-justice/index.llms.md)

主要行动倡议：

- [中国碳中和行动](research/china-carbon-neutrality-initiative/index.llms.md)  
- [纽约气候行动](research/new-york-climate-initiative/index.llms.md)  
- [美国清洁能源行动](research/united-states-clean-energy-initiative/index.llms.md)
